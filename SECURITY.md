# Security Policy

## Supported Versions

Only the latest release of `httpsig` receives security updates. Older releases are not supported. Users are encouraged to upgrade to the latest release to receive security fixes.

## Reporting a Vulnerability

To report a security vulnerability, please use [GitHub Security Advisories](https://github.com/dadrus/httpsig/security/advisories). Do not disclose vulnerabilities through public GitHub issues or other public channels.

We aim to acknowledge vulnerability reports within 48 hours. Confirmed vulnerabilities will be addressed as soon as possible, depending on their severity and complexity.

## Security Updates and Patching

We prioritize timely fixes for confirmed security vulnerabilities, typically provided in patch releases. Security fixes will be documented in the release notes, and a GitHub Security Advisory will be published to inform users of the affected versions and available fixes.
